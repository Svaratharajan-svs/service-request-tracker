# AI Usage Declaration

## 1. Overview

AI-powered tools, including **ChatGPT and Claude**, were used as development assistants during the implementation of this project.

Their usage was primarily limited to improving development productivity, reducing repetitive work, assisting with boilerplate code, and supporting certain development and testing activities.

AI tools were not used to independently design or architect the application, make technical decisions, or autonomously implement the project.

**All architectural decisions, technical design choices, business logic, and final implementation decisions were made by me.**

## 2. Areas Where AI Assistance Was Used

The following activities involved assistance from ChatGPT and Claude:

### 2.1 Boilerplate Code Generation

- Generating repetitive or standard code structures.
- Assisting with initial code templates and common implementation patterns.
- Providing suggestions for reducing repetitive development work.
- Generating basic scaffolding where appropriate.

All generated code was reviewed, adapted, and integrated based on the project's requirements.

### 2.2 Styling and UI Development

- Assisting with CSS and component styling.
- Suggesting layout improvements and responsive styling approaches.
- Generating basic styling structures.
- Improving visual consistency and presentation.

UI behavior, component requirements, and final styling decisions were reviewed and verified by me.

### 2.3 Testing Assistance

- Assisting with test boilerplate and test-case structures.
- Suggesting additional test scenarios and edge cases.
- Helping identify potential issues in existing tests.
- Assisting with debugging test failures and understanding error messages.

I reviewed the suggested tests, verified their relevance to the requirements, and evaluated the test results.

### 2.4 Docker and Development Environment Setup

- Assisting with Dockerfile and Docker Compose boilerplate.
- Suggesting container configuration structures.
- Helping troubleshoot Docker-related configuration issues.
- Assisting with local development environment setup.

The final configurations were reviewed and validated against the project's requirements.

### 2.5 Code Review and Debugging Assistance

AI tools were occasionally used to:
- Explain framework-specific errors and unexpected behavior.
- Suggest possible debugging approaches.
- Identify potential implementation issues.
- Review code snippets and suggest improvements.

Any suggested changes were evaluated before being incorporated into the project.

## 3. Areas Not Delegated to AI

The following responsibilities were handled independently by me:

- Overall application architecture and structure.
- Backend and frontend technology choices.
- Database schema and data modelling decisions.
- API design and endpoint behavior.
- Business logic and application workflows.
- Authentication and authorization design.
- Data integrity and concurrency-handling strategies.
- Transaction management and database consistency decisions.
- Validation rules and application constraints.
- Error-handling strategies.
- Security-related implementation decisions.
- Technical trade-offs and implementation approaches.

AI-generated suggestions were not treated as authoritative technical decisions.

## 4. AI Verification and Responsibility

All AI-assisted outputs incorporated into the project were reviewed and verified by me.

This included:
- Reviewing generated code before integration.
- Checking whether suggested implementations satisfied the requirements.
- Verifying application behavior through manual execution and testing.
- Running relevant automated tests.
- Reviewing Docker configurations and container behavior.
- Evaluating suggested changes for correctness and consistency with the existing architecture.

I take full responsibility for the final codebase, its technical decisions, and the correctness of the implemented functionality.

## 5. Use of AI Agents

No autonomous AI agents or agent-based development workflows were used in this project.

ChatGPT and Claude were used as interactive conversational assistants. They did not independently operate the development environment, make implementation decisions, or autonomously execute the project development process.
